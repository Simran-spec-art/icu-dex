# ICU-DEX

[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.21889605.svg)](https://doi.org/10.5281/zenodo.21889605)

An interactive, browser-based critical care reference built for medical students,
international medical graduates, and early trainees.

## What it does

ICU-DEX consolidates core ICU concepts, drug and device parameters, and bedside
decision frameworks into a single searchable interface that runs entirely in the
browser with no installation and no internet connection required after loading.

## Use

Open `index.html` in any modern browser.

## Disclaimer

**Educational use only.** ICU-DEX has not been validated for clinical decision
making. It does not replace institutional protocols, current prescribing
information, or independent clinical judgment. Verify all doses and parameters
against primary sources before any patient care application.
